# SmartShop for Windows

Point-of-sale and shop management software for Windows. Your shop data stays on your own computer.

## Download
Latest version: https://github.com/zbristan/smartshop-releases/releases/latest

## Install
1. Download SmartShop-VERSION-setup.exe from the latest release.
2. Open it. If Windows says "Windows protected your PC", click More info, then Run anyway. This appears because SmartShop is a new program from a new publisher.
3. Accept the terms and finish the installer.
4. Open SmartShop. It needs the internet once to start your free trial, or enter an activation code from us.

## Check your download (optional)
In PowerShell run: Get-FileHash .\SmartShop-VERSION-setup.exe -Algorithm SHA256
The result must match the checksum file in the release.
